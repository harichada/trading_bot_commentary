FEATURE ENGINEERING GUIDELINES
==============================

1. Stationarity
   - Use returns instead of prices
   - Difference non-stationary series
   - Apply appropriate transformations

2. Normalization
   - Z-score normalization for continuous features
   - Rank-based normalization for robust scaling
   - Min-max scaling for bounded indicators

3. Missing Data Handling
   - Forward fill for prices (max 2 periods)
   - Interpolation for indicators
   - Separate indicator for missing data

4. Lookahead Bias Prevention
   - Strict point-in-time calculations
   - No future information leakage
   - Proper alignment of features and labels

5. Feature Selection
   - Regular SHAP value analysis
   - Recursive feature elimination
   - Cross-validation based selection

6. Feature Categories Priority
   - ESSENTIAL: Price returns, basic TA, volume, time features
   - HIGH VALUE: Microstructure, market context, volatility
   - ADVANCED: ML-derived, statistical, fundamental

RECOMMENDED FEATURE COUNT
=========================
- Minimum viable: 30-50 features
- Optimal range: 100-150 features
- Maximum practical: 200-250 features

Note: More features isn't always better. Focus on:
- Feature quality over quantity
- Low correlation between features
- Strong predictive power
- Computational efficiency
